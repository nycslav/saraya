# Demo script

Build the final demonstration around the principal user flows in `testing.md`. Add speaking
assignments, test accounts, seed-data prerequisites, and fallback screenshots before recording.

The Next Gen RevenueCat segment uses Test Store and should visibly demonstrate:

1. A signed-in user reaching the Saraya paywall.
2. The `default` Offering presenting lifetime Premium and the 10-generation top-up.
3. A Test Store purchase updating server-authoritative entitlement or quota state.
4. The user continuing into itinerary generation.
5. Restore or account-switch behavior if time permits.

The demo does not require Google Play Billing, a Play test track, or store publication. Before
submission, verify that the public repository includes setup instructions, a team-approved
open-source `LICENSE`, and no secrets.
